# AutoStore

## Description
The Car Store Application is a comprehensive platform that allows users to buy new or used cars seamlessly. Customers can browse a variety of vehicle categories, including sedans, supercars, trucks, and SUVs, making it easy to find the perfect car to suit their needs. With an intuitive interface and detailed car listings, this application simplifies the car-buying experience.

## Features
- Buy new or used cars

- Browse by category: Sedan, Supercar, Truck, SUV

- Detailed car listings with specifications

- User-friendly interface

## Configuration

- The Car Store Application allows users to customize and configure various settings to enhance their experience. Below are some key configuration options:

- Database Configuration: Modify database connection settings in config/database.json.

- API Keys: Store and update third-party API keys in .env.

- User Preferences: Adjust application settings through the user dashboard.

- Theme Customization: Change UI themes and layouts in config/ui-settings.json.
